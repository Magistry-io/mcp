# Getting started with Magistry

Magistry connects the systems a business runs on — storefronts, marketplaces, ad platforms, analytics and customer service — and makes them answerable in one conversation.

A good first conversation:

1. List the connected stores (`list_stores`). Most accounts hold more than one.
2. For the store the user means, read the overview (`get_store_overview`): catalogue counts, open alerts, last sync, and which autonomous agents are live or in dry run.
3. Answer the user's actual question from there — ad performance, orders, products, customer-service threads that need attention.

Changes are proposed, not forced: write tools return an approval card that the merchant approves in Magistry, unless the merchant has switched on auto-apply for that connection. Money-moving actions (refunds, gift cards, order cancellations) are not available to connected apps at all.
